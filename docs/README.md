# Todo-App Workflow Docs

Keep docs light in this repo.

Use written docs only when a change is large enough that you want a handoff between sessions or a clear review record.

- `HANDOFF.md` in the repo root is the current state file.
- `docs/plans/` is for scoped plans before implementation.
- `docs/reviews/` is for written review notes and findings.

If a change is tiny and can be done safely in one session, update `HANDOFF.md` and skip extra ceremony.
