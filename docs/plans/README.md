# Plans

Create a file here when a todo-app change affects:
- command behavior in `src/todocli/cli.py`
- data storage or migration logic in `src/todocli/database.py`
- task model semantics in `src/todocli/models.py`
- the optional web surface in `src/todocli/web.py`

Minimum plan sections:
- What this change does
- The real task
- Risks and unknowns
- Acceptance criteria
- Checks
- Rollback
- Copy-paste Claude Code handoff prompt
